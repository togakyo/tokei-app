# とけいが よめるアプリ

アナログ時計を自分で読めるようになるために、小学校低学年の子が Scratch で作っているアプリです。

**あそぶ → https://togakyo.github.io/tokei-app/**

Scratch のアカウントは要りません。リンクを開いて緑の旗を押し、カメラを「許可」してください。

## どんなアプリ？

カメラに時計をかざすと、画面の中で時計の上に色分けしたガイド文字盤がうっすら重なります。

- **赤い数字 = 時**（みじかい針を見る）
- **青い数字 = 分**（ながい針を見る）

それを見ながら自分で読んで、答えを入力すると ○ × がつきます。
答え合わせはパソコンが持っている「いまの時刻」と比べるので、写真は読み取っていません。
**カメラの映像はブラウザの中だけで使われ、どこにも送られません。**

## 中身

```
.
├── index.html      あそぶページ
└── scratch/
    └── tokei_master.sb3   Scratch のファイル。いつもこれ1つ（最新版）
```

`.sb3` は変換していません。TurboWarp の `?project_url=` で直接読みこんでいます。
自分の Scratch で開きたいときは `.sb3` をダウンロードして、
Scratch の「ファイル → コンピューターから読みこむ」を選んでください。

## 更新のしかた 〈おとな〉

記録用の private リポジトリ `tokei-project` 側で `scripts/publish.sh` を実行すると、
`tokei_master.sb3` のコピー・更新日の書きかえ・push まで自動でやります。
ファイル名は常に同じで、中身を上書きしていきます。むかしの版は git の履歴に残ります。
